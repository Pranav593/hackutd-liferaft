# LIFERAFT MVP upgrade

Your training job never finds out the machine was dying.

This slice adds a judge-facing **read-only presentation replay** at `/story`.
The original cockpit and trusted recovery core remain intact. One command
prepares real local drills and opens the presentation server. Presentation
controls select saved drills; they never execute commands from the browser.

| Feature | Track | MVP implementation / provenance |
|---|---|---|
| Predict | General / NorthMark | Validated, timestamped injected CPU trend; linear forecast with fit quality, not a calibrated probability. No heat or fan changes. Existing measured Pi collector remains available. |
| Decide | NVIDIA / NorthMark | Journaled read-only tool registry and deterministic fallback. Optional existing Nemotron investigation uses its validated evidence tools; no model can fence or migrate. |
| Evacuate | General / NorthMark | Existing two-process CPU PyTorch worker, leases, epochs and verified checkpoint restore. Same computer, not newly demonstrated cross-device. |
| Prove / ghost run | General / NorthMark | Newly executed uninterrupted baseline, every loss compared exactly and final model tensors compared; actual maximum divergence and checkpoint hash. Crash RPO stays unknown. |
| Chaos | General | Cooling prediction, killed training process, damaged disposable local checkpoint, stale-epoch commit. All use the existing coordinator. Network partition remains outside this MVP. |
| Brief | Photon / NorthMark | Offline message transport, clearly simulated; APPROVE/HOLD/ROLLBACK are rehearsal-only responses. Existing signed live Photon STATUS/ACK path stays intact. No new live approval authority. |
| Presentation | All | Lazy Three.js constellation, forecast ring, real loss overlay, expandable tool trace, hash-chain recorder, captions, money estimate with visible inputs. Explicit Run button; replay never starts automatically. |

## Phases

U0: contracts, predictor, rehearsal runner, focused safety tests; verify before U1.
U1: presentation cockpit and one-command start; typecheck, production build,
browser QA. U2: documentation, complete regression run and evidence log.

No new dependency, cloud deployment, real heating, hardware wiring or purchase
is needed. The offline path does not consume provider keys. Live Nemotron and
Photon operation use the existing operator commands and setup guides. Their
historical success is not new evidence for this replay.
